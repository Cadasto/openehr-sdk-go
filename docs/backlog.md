# Backlog

Leftovers of merged branches: defects the branch that found them did not fix, and suggestions. Each line is a lead, not a finding: verify it before acting. Lines are grouped by theme so one delivery can take a whole group; the sentence under each heading says what such a delivery is. A delivery whose `Files` touch a line's path verifies it, and fixes it or finds it stale; the next `/sdd-triage --backlog` deletes what is settled. `sdd-pr harvest` and `sdd-pr flip --carry` add new lines under `## Unsorted`, defects first; the next `/sdd-triage --backlog` sorts them into a group. Groups are ordered by what a caller loses: data first, then the shape of a failure, then example quality, coverage, performance and tooling. The file is kept at about 80 entries ([AGENTS.md § Spec-driven workflow](../AGENTS.md#spec-driven-workflow-agents)). Edit freely.
