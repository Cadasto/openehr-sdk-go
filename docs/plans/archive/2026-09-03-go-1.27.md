# Plan — Go 1.27 floor and stdlib adoption

**Date:** 2026-09-03
**Status:** Draft
**Owner:** SDK maintainers
**Covers:** [REQ-002](../specifications/packaging.md#req-002--go-version); informative STRAND-04 note (json/v2 now stable — **no** codec migration)
**Probes:** none (toolchain + equivalent rewrites; no wire behaviour change)
**Implementation:** ready for review (unpushed `build/go-1.27`)
**Depends on:** Go 1.27.0 stable (released 2026-08-19); latest patch at authoring is 1.27.1
**Defers:** `encoding/json/v2` / `jsontext` canjson migration (STRAND-04 fit-gap + ADR); `uuid.Parse` for `detectUID`; SIMD; turning package-level generics into methods (REQ-023); blanket `httptest.NewTestServer` swap

## Goal

Raise the module floor to the current stable Go line (`go 1.27.0` in `go.mod`, REQ-002) and adopt the 1.27 language/stdlib wins that simplify existing code without changing openEHR wire behaviour: `go fix embedlit`, `strings.CutLast`, stdlib `uuid` for v4 generation, `(*typereg.Registry).DecodeAs`, `url.URL.Clone` in `joinTarget`, `math/rand/v2` `(*Rand).N` on the instance sampler, and `testing/synctest` + `httptest.NewTestServer` on the four real-clock sleep tests.

Consumers must build with Go ≥ 1.27.0 (minor SemVer bump at the next tag).

## Definition of Ready

- **`**Covers:**`** lists REQ-002; STRAND-04 is documentation-only.
- Canonical REQ-002 prose already exists; this plan only refreshes the informative `1.26.0` examples to `1.27.0`.
- No new ADR: json/v2 stays open on STRAND-04; promoted-field literals and CutLast are mechanical.
- Phases name verification (`make spec-check`, `go test ./...`, `make lint` / `make ci` as far as the host toolchain allows).

## Definition of Done

- `go.mod` `go` line is `1.27.0`; CI/Docker/Make host-fast-path regex track `1.27.x`; Dockerfile pin is a 1.27.x patch ≥ 1.27.0.
- Informative spec/docs examples say 1.27.0 / 1.27.x.
- 1.27 rewrites land; existing tests still pass; synctest tests replace `time.Sleep` on the four listed cases.
- `make spec-check` passes. `go test ./...` passes on Go 1.27.
- Plan stays active until the implementing PR merges, then archive.

## Out of scope (do not adopt)

| Item | Why |
|---|---|
| `uuid.Parse` replacing `uuidRE` | `detectUID` is lexical 8-4-4-4-12; Parse also accepts URN, braces, 32-hex |
| json/v2 in canjson / jsonpoly / typereg | STRAND-04; v2 defaults reject invalid UTF-8 and duplicate names |
| Generic methods on `transport.Decode`, contribution builders | REQ-023 package-level surface |
| `slices.Backward` on `extractLastPathSegment` | CutLast is simpler |
| SIMD, crypto/mldsa, `tls.Config` ML-KEM | Experimental or consumer TLS |

## Phases

### Phase 0 — Spec and plan indexes

Refresh REQ-002 informative examples (`go 1.26.0` → `go 1.27.0`) in packaging.md, module-layout.md, idiom.md floor sentence. Note in STRAND-04 that `encoding/json/v2` is stable in Go 1.27 (no longer `GOEXPERIMENT=jsonv2`); the fit-gap remains open. Add this plan to `docs/plans/README.md`.

**Definition of done:** `make spec-check` still green; no new REQ id.

### Phase 1 — Toolchain floor

- `go.mod`: `go 1.27.0` (never a mid-line patch; no `toolchain` line).
- GitHub Actions (`ci.yml`, `codegen-drift.yml`, `release.yml`): `go-version: '1.27.x'`.
- Dockerfile `ARG GO_VERSION=1.27.1` (build pin; independent of the `.0` floor).
- Makefile `HOST_GO_OK` regex and “fast path” comments: `1.27.x`.
- docker-compose.yml, AGENTS.md, CONTRIBUTING.md, docs/ci.md, docs/quick-start.md, bug-report placeholder.
- CHANGELOG Unreleased: one terse REQ-002 bullet.

**Definition of done:** `go version` under this module reports a 1.27 toolchain (`GOTOOLCHAIN=auto`); `make doctor` treats host 1.27 as the fast path.

### Phase 2 — `go fix embedlit`

Run `go fix -fix=embedlit ./...` (or equivalent 1.27 modernizer). Review: skip `LocatableRef` tests that set the shadowed parent `ObjectRef.ID`; skip literals where the inner value is already a variable.

**Definition of done:** `gofmt` clean; tests that construct `DVCodedText` / `PartyRef` / `DVEHRURI` still pass.

### Phase 3 — `strings.CutLast`

Rewrite LastIndex+slice split sites that want before/after/found:

- `openehr/serialize/simplified/flat_decode.go` `splitSuffix`, `parseFlatKey`
- `openehr/serialize/simplified/rmattr_value.go` `rmattrSegIndex`
- `openehr/client/ehr/ids.go` `extractVersionUIDFromLocation`
- `openehr/client/definition/template.go` `extractLastPathSegment`
- `openehr/rm/identification_funcs.go` `Specialisation` (LastIndexByte `-`)
- `testkit/fixtures/parse_opt.go` OPT closing-tag splice

Leave: AQL last-line `LastIndex("\n")+1`; `temporal_funcs.go` (`i > 0`); archetype first+last `.`.

**Definition of done:** existing identifier / FLAT / Location tests pass.

### Phase 4 — Stdlib helpers

- `newHierObjectID`: `uuid.NewV4().String()` (stdlib `uuid`). Keep a distinct-id fallback if `crypto/rand` fails, or document the drop — prefer keeping the timestamp fallback around a `rand.Read` then format, if `NewV4` has no error path.
- `(*Registry).DecodeAs[T]`; package `DecodeAs` delegates to `Default`. Pin with a registry_test that calls the method on a non-Default registry (`// REQ-002` not required; existing DecodeAs tests stay).
- `joinTarget`: `base.Clone()` instead of `out := *base`. Leave `sanitisedURL` shallow.
- `sampler`: collapse `intN`/`int64N` onto `(*Rand).N` / `rand/v2.N`.

**Definition of done:** instance UID tests, typereg DecodeAs tests, transport path tests pass.

### Phase 5 — synctest (four tests only)

Wrap in `synctest.Test`, use `httptest.NewTestServer`, drop `time.Sleep`:

- `smart/discovery/resolver_test.go` `TestResolveCacheExpiry` → `synctest.Sleep` past TTL
- `smart/discovery/resolver_test.go` `TestResolveCoalescesConcurrent` → `synctest.Wait` then `close(gate)`
- `auth/clientcreds/clientcreds_test.go` `TestTokenConcurrentCoalesce` — same
- `auth/jwtbearer/jwtbearer_test.go` `TestSourceCoalescesConcurrent` — same

Do not convert the rest of `httptest.NewServer`.

**Definition of done:** those four tests pass under `-count=1` without real-time sleeps.

### Phase 6 — Verify

`make spec-check`, `gofmt`/`make fmt-check`, `go test ./... -count=1`, `make lint` if host golangci-lint accepts 1.27, else note. Full `make ci` needs Docker (aqlgen-verify).
